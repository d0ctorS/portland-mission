# Миссия: Футболка Портленда

Законченная браузерная 2D-игра о доставке футболки другу через зимнюю Москву. TypeScript, Phaser 3.90, Vite. Всё выполняется на клиенте. Регистрация и сервер не нужны.

## Запуск

Установите Node.js 22 LTS. В папке проекта выполните:

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://localhost:5173/portland-mission/). Для телефона в той же Wi-Fi сети используйте сетевой адрес Vite, также с `/portland-mission/`.

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Открывать `index.html` двойным щелчком нельзя: нужен HTTP-сервер.

## Управление и сюжет

WASD / стрелки — движение, E — разговор и следующая реплика, Enter — следующая реплика, Escape — пауза. На сенсорных устройствах есть джойстик и E. Потеря фокуса ставит игру на паузу, чтобы не увеличивать время прохождения. Во время разговоров таймер также приостановлен.

Выберите Санька или Марка. Владелец футболки находится на северо-востоке карты (Ф), СДЭК — на юго-западе (С), Денчик и поезд — на юго-востоке (В). Мини-карта показывает улицы и точки, но не прокладывает маршрут. Поход в СДЭК необязателен и не позволяет пропустить сюжет. Получите футболку, передайте Денчику и досмотрите сцену с шоколадкой и отправлением поезда. Лучшее время сохраняется локально в браузере.

Карта генерируется с фиксированным seed: 39 × 31 клетка, алгоритм DFS (seed 7217), дополнительные проходы и площадки у сюжетных точек. Размер мира 3744 × 2976 пикселей. Скорость 172 px/s. Кратчайший путь двух сюжетных этапов занимает около пяти минут ходьбы; с исследованием и диалогами ориентир — 5–10 минут.

## GitHub Pages — первая публикация

1. Создайте **публичный** репозиторий `portland-mission` в своём GitHub.
2. Загрузите содержимое именно этой папки в корень репозитория, включая `.github/workflows/deploy.yml` и `package-lock.json`. Не загружайте `node_modules`.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
4. Отправьте изменения в ветку `main`. Либо запустите **Actions → Deploy game to GitHub Pages → Run workflow**.
5. После успешного выполнения откройте URL из шага Deploy. Формат: `https://ВАШ_ЛОГИН.github.io/portland-mission/`.

Через терминал, если GitHub CLI уже установлен и авторизован:

```sh
git init -b main
git add .
git commit -m "Build Portland mission game"
gh repo create portland-mission --public --source=. --remote=origin --push
# Затем выбрать GitHub Actions в Settings → Pages и повторить workflow.
```

`base` уже настроен в `vite.config.ts` как `/portland-mission/`. При переименовании репозитория измените этот параметр. Дальнейшие push в main запускают тесты, TypeScript-проверку, сборку и публикацию автоматически.

## Структура

- `src/scenes/screens.ts`: меню, выбор героя, победа.
- `src/scenes/world.ts`: исследование, взаимодействия, пауза, мини-карта, сенсорное управление.
- `src/scenes/finale.ts`: передача футболки, радость Денчика, награда и уходящий поезд.
- `src/game/player.ts`: Player и NPC, спрайты и физика.
- `src/game/map.ts`, `city.ts`: лабиринт, декорации, снег и вокзал.
- `src/game/state.ts`: Inventory, QuestManager, таймер и рекорд.
- `src/game/ui.ts`: DialogueManager и интерфейс.
- `src/game/audio.ts`: AudioManager и оригинальная синтезированная музыка.
- `src/game/art.ts`: оригинальные программные пиксельные текстуры.
- `tests/`: тесты достижимости, инвентаря, таймера и перезапуска. `npm run test:browser` — полный сценарий Playwright (сначала `npx playwright install chromium` и `npm run dev`).

## Ресурсы и лицензии

Шрифт Golos Text хранится локально, лицензия SIL OFL лежит в `public/fonts/OFL.txt`. Внешние ресурсы при игре не загружаются.

Графика и мелодии созданы специально для этого проекта программно. Официальные логотипы не используются. Phaser распространяется по MIT, Vite — по MIT, TypeScript — по Apache-2.0. Звук включается только после действия пользователя. Пользовательские данные никуда не отправляются, `localStorage` хранит только рекорд.

Для проверки через браузер тестовые функции доступны только при `npm run dev` с `?qa=1`: `window.__mission` — текущая игровая сцена. В production доступ отсутствует. Это инструмент разработчика, обычное прохождение не требует консоли.

## Быстрый запуск на этом Mac

Дважды щёлкните `Запустить игру.command`. В исходном рабочем расположении он использует уже загруженный локальный Node.js из папки `work/`, если системного Node.js нет. После переноса или распаковки на другой компьютер установите Node.js 22 LTS. Закрытие окна терминала останавливает игру. Для доступа с телефона терминал должен оставаться открытым.

## Публичная игра

Игра опубликована и открыта в браузере: **https://d0ctors.github.io/portland-mission/**.

Код: https://github.com/d0ctorS/portland-mission. GitHub Pages настроен на GitHub Actions; workflow `.github/workflows/deploy.yml` после каждого push в `main` выполняет тесты, сборку и публикацию. Собственный сервер и Vercel не используются.

Для следующих изменений откройте эту папку в GitHub Desktop, создайте коммит и нажмите **Push origin**. После зелёного workflow друзья увидят обновлённую игру по той же ссылке. Основная рабочая папка содержит `.git` и настроенный origin; ZIP с исходниками содержит только файлы проекта.

Результаты и ограничения проверки записаны в `TESTING.md`.
